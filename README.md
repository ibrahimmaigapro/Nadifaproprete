# Nadifa Propreté — site vitrine

Site statique (HTML/CSS/JS sans dépendance) de Nadifa Propreté, nettoyage à domicile à Toulouse.

- Les pages HTML sont **générées** par `build.py` : modifier le script puis lancer `python3 build.py`, ne pas éditer les `.html` à la main.
- Hébergement : GitHub Pages (branche `main`, racine). Le fichier `.nojekyll` est requis.
- Images : `assets/img/` en WebP (480/800/1400 px).

Site publié : https://ibrahimmaigapro.github.io/Nadifaproprete/ (puis https://nadifaproprete.fr).
